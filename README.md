# CygniTasks - Frontend

## Descrição

CygniTasks é um gerenciador de tarefas com uma pegada espacial, inspirado na constelação de Cygnus. O projeto foi desenvolvido utilizando **React.js**, **TypeScript** e **Tailwind CSS**, e oferece uma interface simples e intuitiva para gerenciar suas tarefas. O design foi pensado para ser clean e agradável, com uma paleta de cores e ícones que trazem a temática espacial para a aplicação.

## Tecnologias Utilizadas

- **React**: Lib para a construção da aplicação.
- **TypeScript**: Para tipagem estática.
- **Tailwind CSS**: Para estilização.
- **React-Icons**: Biblioteca de ícones para uso em componentes React.

## Funcionalidades

- **Tela de Login/Cadastro**: Autenticação com JWT.
- **Gerenciamento de Tarefas**: Interface para criar, visualizar, editar e excluir tarefas.
- **Roteamento de Páginas**: Navegação entre diferentes páginas para organizar as tarefas e exibir informações detalhadas.
